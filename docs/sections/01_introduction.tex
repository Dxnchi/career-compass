\section{Introduction}
\subsection{Project Purpose}
Career Compass is an integrated cross-platform solution designed to match individuals with target career trajectories and identify actionable skill gaps. 

\subsection{Monorepo Structure}
The project employs a monorepo topology structured into three distinct domains:
\begin{itemize}
    \item \textbf{mobile/}: React Native client application featuring camera-based capture and offline persistence.
    \item \textbf{server/}: Node.js and Express backend service housing the core career-matching engine.
    \item \textbf{docs/}: Technical architectural specifications, UML schematics, and design system contracts.
\end{itemize}
