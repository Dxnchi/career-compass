Career Compass
Career Compass is an offline-first mobile application designed to seamlessly match high school students with eligible university programmes. By scanning report cards, the deterministic engine extracts grades and cross-references them with university admission requirements to provide accurate, instant feedback.

Core Tech Stack

Frontend: React Native (Expo)

Backend Engine: Node.js & Express

Database: SQLite (Local persistence for offline capabilities)

Development Workflow
We utilize a strict feature-branch architecture. Code is never pushed directly to main or development. All modules are built on designated feature/* branches and integrated via Pull Requests.
